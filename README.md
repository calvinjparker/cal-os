# cal-os

Calvin's personal life OS: a private, installable web app (Next.js + TypeScript), hosted on Vercel with Supabase for data and login.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deploy

Vercel deploys automatically: every pull request gets a preview link, and merging to `main` updates production.

See `CLAUDE.md` for the stack, workflow, and rules.
